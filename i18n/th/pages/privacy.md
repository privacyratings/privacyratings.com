# นโยบายความเป็นส่วนตัว

Privacy Ratings ไม่ตั้งคุกกี้ ไม่ใช้เครื่องมือวิเคราะห์ และไม่โหลดสิ่งใดจากเว็บไซต์อื่น หน้านี้อธิบายทุกสิ่งที่เกิดขึ้นจริงเมื่อคุณเข้าชมเว็บไซต์หรือใช้เครื่องมือบรรทัดคำสั่ง

## โฮสติ้ง

เว็บไซต์นี้ให้บริการผ่าน [GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages#data-collection) GitHub บันทึกที่อยู่ IP ของผู้เข้าชมทุกคนเพื่อความปลอดภัย ตามที่อธิบายไว้ใน [GitHub General Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement) Privacy Ratings ไม่มีเซิร์ฟเวอร์ของตัวเองและเข้าถึงบันทึกเหล่านั้นไม่ได้

## สิ่งที่เว็บไซต์เก็บไว้ในเบราว์เซอร์ของคุณ

- `theme`: ธีมสี หากคุณเลือกไว้
- `lang`: ภาษาที่คุณเลือก หรือภาษาที่ตรงกับเบราว์เซอร์ของคุณในการเข้าชมครั้งแรก
- `mastodon`: เซิร์ฟเวอร์ Mastodon ที่คุณพิมพ์ในเมนูแชร์ หากคุณใช้งาน
- Service worker เก็บสำเนาของหน้าที่คุณเปิด เพื่อให้ใช้งานได้แบบออฟไลน์

ข้อมูลทั้งหมดอยู่บนอุปกรณ์ของคุณ การล้างข้อมูลเว็บไซต์ในเบราว์เซอร์จะลบข้อมูลเหล่านี้

## คำขอไปยังเว็บไซต์อื่น

สคริปต์ สไตล์ชีต ฟอนต์ รูปภาพ และวิดีโอทั้งหมดโหลดจาก privacyratings.com และ Content Security Policy จะบล็อกสิ่งอื่นทั้งหมด ลิงก์ไปยังเว็บไซต์อื่น รวมถึงลิงก์แชร์ จะไม่โหลดอะไรจนกว่าคุณจะเปิด

## การค้นหา

ช่องค้นหาดาวน์โหลดดัชนีการค้นหาจากเว็บไซต์นี้และกรองในเบราว์เซอร์ของคุณ ในหน้าค้นหา คำที่คุณค้นจะปรากฏในที่อยู่ของหน้า เหมือนลิงก์อื่นๆ

## เครื่องมือบรรทัดคำสั่ง

เครื่องมือบรรทัดคำสั่ง `privacyratings` ไม่ส่งข้อมูลวิเคราะห์หรือเทเลเมทรี เครื่องมือนี้ดาวน์โหลดการจัดอันดับจากเว็บไซต์นี้ และตรวจสอบรุ่นใหม่ผ่าน GitHub API วันละครั้ง หากมีรุ่นที่ใหม่กว่า เครื่องมือจะอัปเดตตัวเองจาก GitHub หรือผ่าน npm ตั้งค่า `PRIVACYRATINGS_NO_UPDATE=1` หรือใช้ `--no-update` เพื่อปิดการอัปเดต

## การมีส่วนร่วม

Issue, pull request และการสนทนาเกิดขึ้นบน GitHub และเป็นสาธารณะ บัญชี GitHub ของคุณอยู่ภายใต้ GitHub General Privacy Statement

## ติดต่อ

สอบถามเกี่ยวกับนโยบายนี้ได้ที่ [issue บน GitHub](https://github.com/privacyratings/privacyratings.com/issues) รายงานปัญหาด้านความปลอดภัยตามที่อธิบายไว้ใน [SECURITY.md](https://github.com/privacyratings/privacyratings.com/blob/main/SECURITY.md)
