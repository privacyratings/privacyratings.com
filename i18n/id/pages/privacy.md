# Kebijakan privasi

Privacy Ratings tidak memasang cookie, tidak menjalankan analitik, dan tidak memuat apa pun dari situs lain. Halaman ini menjelaskan semua yang memang terjadi saat Anda mengunjungi situs atau memakai alat baris perintah.

## Hosting

Situs ini disajikan oleh [GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages#data-collection). GitHub mencatat alamat IP setiap pengunjung untuk keperluan keamanan, seperti dijelaskan dalam [GitHub General Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). Privacy Ratings tidak menjalankan server sendiri dan tidak punya akses ke log tersebut.

## Yang disimpan situs di peramban Anda

- `theme`: tema warna, jika Anda memilihnya.
- `lang`: bahasa yang Anda pilih, atau bahasa yang cocok dengan peramban Anda pada kunjungan pertama.
- `mastodon`: server Mastodon yang Anda ketik di menu berbagi, jika Anda memakainya.
- Service worker menyimpan salinan halaman yang Anda buka agar bisa dipakai secara luring.

Semuanya tetap di perangkat Anda. Menghapus data situs di peramban akan menghapusnya.

## Permintaan ke situs lain

Semua skrip, stylesheet, fon, gambar, dan video dimuat dari privacyratings.com, dan Content Security Policy memblokir yang lain. Tautan ke situs lain, termasuk tautan berbagi, tidak memuat apa pun sampai Anda membukanya.

## Pencarian

Kotak pencarian mengunduh indeks pencarian dari situs ini dan menyaringnya di peramban Anda. Di halaman pencarian, kata kunci Anda muncul di alamat halaman, seperti tautan lainnya.

## Alat baris perintah

Alat baris perintah `privacyratings` tidak mengirim analitik atau telemetri. Alat ini mengunduh penilaian dari situs ini dan memeriksa GitHub API sekali sehari untuk rilis baru. Jika ada versi yang lebih baru, alat ini memperbarui dirinya dari GitHub atau dengan npm. Atur `PRIVACYRATINGS_NO_UPDATE=1` atau gunakan `--no-update` untuk mematikan pembaruan.

## Kontribusi

Issue, pull request, dan diskusi berlangsung di GitHub dan bersifat publik. GitHub General Privacy Statement berlaku untuk akun GitHub Anda.

## Kontak

Ajukan pertanyaan tentang kebijakan ini lewat [issue di GitHub](https://github.com/privacyratings/privacyratings.com/issues). Laporkan masalah keamanan seperti dijelaskan di [SECURITY.md](https://github.com/privacyratings/privacyratings.com/blob/main/SECURITY.md).
