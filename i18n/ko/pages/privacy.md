# 개인정보 처리방침

Privacy Ratings는 쿠키를 설정하지 않고, 분석 도구를 사용하지 않으며, 다른 사이트에서 아무것도 불러오지 않습니다. 이 페이지는 사이트를 방문하거나 명령줄 도구를 사용할 때 실제로 일어나는 모든 일을 설명합니다.

## 호스팅

이 사이트는 [GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages#data-collection)에서 제공됩니다. [GitHub General Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)에 설명된 대로 GitHub는 보안을 위해 모든 방문자의 IP 주소를 기록합니다. Privacy Ratings는 자체 서버를 운영하지 않으며 이 기록에 접근할 수 없습니다.

## 사이트가 브라우저에 저장하는 것

- `theme`: 선택한 색상 테마(선택한 경우).
- `lang`: 선택한 언어, 또는 처음 방문했을 때 브라우저와 일치한 언어.
- `mastodon`: 공유 메뉴에 입력한 Mastodon 서버(사용한 경우).
- 서비스 워커가 열어 본 페이지의 사본을 보관해 오프라인에서도 열 수 있게 합니다.

모든 정보는 기기에만 남습니다. 브라우저에서 사이트 데이터를 지우면 삭제됩니다.

## 다른 사이트로 보내는 요청

모든 스크립트, 스타일시트, 글꼴, 이미지, 동영상은 privacyratings.com에서 불러오며, Content Security Policy가 그 밖의 모든 것을 차단합니다. 공유 링크를 포함한 다른 사이트 링크는 직접 열기 전까지 아무것도 불러오지 않습니다.

## 검색

검색창은 이 사이트에서 검색 색인을 내려받아 브라우저 안에서 걸러 냅니다. 검색 페이지에서는 다른 링크와 마찬가지로 검색어가 페이지 주소에 표시됩니다.

## 명령줄 도구

명령줄 도구 `privacyratings`는 분석 데이터나 원격 측정 데이터를 보내지 않습니다. 이 사이트에서 평가를 내려받고, 하루에 한 번 GitHub API로 새 릴리스를 확인합니다. 더 새로운 버전이 있으면 GitHub 또는 npm으로 스스로 업데이트합니다. 업데이트를 끄려면 `PRIVACYRATINGS_NO_UPDATE=1`을 설정하거나 `--no-update`를 사용하세요.

## 기여

이슈, 풀 리퀘스트, 토론은 GitHub에서 공개적으로 진행됩니다. GitHub 계정에는 GitHub General Privacy Statement가 적용됩니다.
