# Chính sách quyền riêng tư

Privacy Ratings không đặt cookie, không chạy công cụ phân tích và không tải gì từ trang web khác. Trang này liệt kê mọi điều thực sự xảy ra khi bạn truy cập trang web hoặc dùng công cụ dòng lệnh.

## Lưu trữ

[GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages#data-collection) phục vụ trang web này. GitHub ghi lại địa chỉ IP của mọi khách truy cập vì mục đích bảo mật, như mô tả trong [GitHub General Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). Privacy Ratings không vận hành máy chủ riêng và không truy cập được các nhật ký đó.

## Trang web lưu gì trong trình duyệt của bạn

- `theme`: chủ đề màu, nếu bạn đã chọn.
- `lang`: ngôn ngữ bạn đã chọn, hoặc ngôn ngữ khớp với trình duyệt của bạn ở lần truy cập đầu tiên.
- `mastodon`: máy chủ Mastodon bạn đã nhập trong menu chia sẻ, nếu bạn dùng nó.
- Một service worker giữ bản sao các trang bạn đã mở để chúng dùng được khi ngoại tuyến.

Tất cả đều nằm trên thiết bị của bạn. Xóa dữ liệu trang web trong trình duyệt sẽ xóa chúng.

## Yêu cầu tới trang web khác

Mọi script, stylesheet, phông chữ, hình ảnh và video đều tải từ privacyratings.com, và Content Security Policy chặn mọi thứ khác. Liên kết tới trang web khác, kể cả liên kết chia sẻ, không tải gì cho đến khi bạn mở chúng.

## Tìm kiếm

Ô tìm kiếm tải chỉ mục tìm kiếm từ trang web này và lọc ngay trong trình duyệt của bạn. Trên trang tìm kiếm, từ khóa của bạn xuất hiện trong địa chỉ trang, như mọi liên kết khác.

## Công cụ dòng lệnh

Công cụ dòng lệnh `privacyratings` không gửi dữ liệu phân tích hay telemetry. Công cụ tải các đánh giá từ trang web này và kiểm tra GitHub API mỗi ngày một lần để tìm bản phát hành mới. Nếu có bản mới hơn, công cụ tự cập nhật từ GitHub hoặc qua npm. Đặt `PRIVACYRATINGS_NO_UPDATE=1` hoặc dùng `--no-update` để tắt cập nhật.

## Đóng góp

Issue, pull request và thảo luận diễn ra trên GitHub và đều công khai. GitHub General Privacy Statement áp dụng cho tài khoản GitHub của bạn.

## Liên hệ

Đặt câu hỏi về chính sách này trong một [issue trên GitHub](https://github.com/privacyratings/privacyratings.com/issues). Báo cáo vấn đề bảo mật theo hướng dẫn trong [SECURITY.md](https://github.com/privacyratings/privacyratings.com/blob/main/SECURITY.md).
