# 隐私政策

Privacy Ratings 不设置 Cookie，不运行任何分析工具，也不从其他网站加载任何内容。本页列出你访问本站或使用命令行工具时实际发生的所有事情。

## 托管

本站由 [GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages#data-collection) 提供。正如 [GitHub General Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement) 所述，GitHub 出于安全目的会记录每位访问者的 IP 地址。Privacy Ratings 没有自己的服务器，也无法访问这些日志。

## 本站在你的浏览器中保存的内容

- `theme`: 颜色主题（如果你选择过）。
- `lang`: 你选择的语言，或首次访问时与你的浏览器匹配的语言。
- `mastodon`: 你在分享菜单中输入的 Mastodon 服务器（如果用过）。
- Service Worker 会保存你打开过的页面副本，以便离线使用。

这些内容都只保存在你的设备上。在浏览器中清除本站数据即可删除。

## 对其他网站的请求

所有脚本、样式表、字体、图片和视频都从 privacyratings.com 加载，内容安全策略（Content Security Policy）会阻止其他一切。指向其他网站的链接（包括分享链接）在你打开之前不会加载任何内容。

## 搜索

搜索框会从本站下载搜索索引，并在你的浏览器中筛选。在搜索页面上，你输入的词会像其他链接一样出现在页面地址中。

## 命令行工具

命令行工具 `privacyratings` 不发送任何分析或遥测数据。它从本站下载评分，并每天通过 GitHub API 检查一次是否有新版本。如有更新的版本，它会通过 GitHub 或 npm 更新自身。设置 `PRIVACYRATINGS_NO_UPDATE=1` 或使用 `--no-update` 可关闭更新。

## 参与贡献

Issue、拉取请求和讨论都在 GitHub 上公开进行。你的 GitHub 账户适用 GitHub General Privacy Statement。

## 联系方式

如对本政策有疑问，请在 [GitHub Issue](https://github.com/privacyratings/privacyratings.com/issues) 中提出。安全问题请按 [SECURITY.md](https://github.com/privacyratings/privacyratings.com/blob/main/SECURITY.md) 中的说明报告。
