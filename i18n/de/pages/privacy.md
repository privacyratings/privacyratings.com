# Datenschutzerklärung

Privacy Ratings setzt keine Cookies, nutzt keine Analyse und lädt nichts von anderen Websites. Diese Seite beschreibt alles, was tatsächlich passiert, wenn Sie die Website besuchen oder das Kommandozeilen-Tool nutzen.

## Hosting

[GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages#data-collection) stellt diese Website bereit. GitHub protokolliert die IP-Adresse jeder besuchenden Person aus Sicherheitsgründen, wie im [GitHub General Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement) beschrieben. Privacy Ratings betreibt keinen eigenen Server und hat keinen Zugriff auf diese Protokolle.

## Was die Website in Ihrem Browser speichert

- `theme`: das Farbschema, falls Sie eines gewählt haben.
- `lang`: die Sprache, die Sie gewählt haben, oder die, die bei Ihrem ersten Besuch zu Ihrem Browser passte.
- `mastodon`: der Mastodon-Server, den Sie im Teilen-Menü eingegeben haben, falls Sie es genutzt haben.
- Ein Service Worker speichert Kopien der Seiten, die Sie geöffnet haben, damit sie offline funktionieren.

Alles bleibt auf Ihrem Gerät. Wenn Sie die Website-Daten in Ihrem Browser löschen, wird es entfernt.

## Anfragen an andere Websites

Alle Skripte, Stylesheets, Schriften, Bilder und Videos werden von privacyratings.com geladen, und eine Content Security Policy blockiert alles andere. Links zu anderen Websites, auch die Teilen-Links, laden nichts, bis Sie sie öffnen.

## Suche

Das Suchfeld lädt den Suchindex von dieser Website und filtert ihn in Ihrem Browser. Auf der Suchseite stehen Ihre Suchbegriffe in der Seitenadresse, wie bei jedem anderen Link.

## Kommandozeilen-Tool

Das Kommandozeilen-Tool `privacyratings` sendet keine Analyse- oder Telemetriedaten. Es lädt Bewertungen von dieser Website und prüft einmal am Tag über die GitHub-API, ob es eine neue Version gibt. Gibt es eine neuere Version, aktualisiert es sich selbst über GitHub oder npm. Setzen Sie `PRIVACYRATINGS_NO_UPDATE=1` oder verwenden Sie `--no-update`, um Updates abzuschalten.

## Beiträge

Issues, Pull Requests und Diskussionen finden auf GitHub statt und sind öffentlich. Für Ihr GitHub-Konto gilt das GitHub General Privacy Statement.
