# Privatlivspolitik

Privacy Ratings sætter ingen cookies, kører ingen analyse og indlæser intet fra andre websteder. Denne side beskriver alt, hvad der faktisk sker, når du besøger webstedet eller bruger kommandolinjeværktøjet.

## Hosting

Webstedet leveres af [GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages#data-collection). GitHub logger IP-adressen på alle besøgende af sikkerhedshensyn, som beskrevet i [GitHub General Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). Privacy Ratings har ingen egen server og har ikke adgang til disse logfiler.

## Hvad webstedet gemmer i din browser

- `theme`: farvetemaet, hvis du har valgt et.
- `lang`: det sprog, du har valgt, eller det, der passede til din browser ved dit første besøg.
- `mastodon`: den Mastodon-server, du skrev i delingsmenuen, hvis du brugte den.
- En service worker gemmer kopier af de sider, du har åbnet, så de virker offline.

Det hele bliver på din enhed. Når du rydder webstedets data i din browser, fjernes det.

## Forespørgsler til andre websteder

Alle scripts, stylesheets, skrifttyper, billeder og videoer indlæses fra privacyratings.com, og en Content Security Policy blokerer alt andet. Links til andre websteder, også delingslinks, indlæser intet, før du åbner dem.

## Søgning

Søgefeltet henter søgeindekset fra dette websted og filtrerer det i din browser. På søgesiden står dine søgeord i sidens adresse, ligesom i ethvert andet link.

## Kommandolinjeværktøj

Kommandolinjeværktøjet `privacyratings` sender ingen analyse eller telemetri. Det henter bedømmelser fra dette websted og tjekker GitHub API én gang om dagen for en ny version. Findes der en nyere version, opdaterer det sig selv fra GitHub eller med npm. Sæt `PRIVACYRATINGS_NO_UPDATE=1` eller brug `--no-update` for at slå opdateringer fra.

## Bidrag

Issues, pull requests og diskussioner foregår på GitHub og er offentlige. GitHub General Privacy Statement gælder for din GitHub-konto.

## Kontakt

Stil spørgsmål om denne politik i et [issue på GitHub](https://github.com/privacyratings/privacyratings.com/issues). Rapportér sikkerhedsproblemer som beskrevet i [SECURITY.md](https://github.com/privacyratings/privacyratings.com/blob/main/SECURITY.md).
